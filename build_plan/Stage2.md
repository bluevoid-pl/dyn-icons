# Stage 2 - Demo Project Reproduction

## Purpose
The demo app validates `dyn-icons` + `dyn-icons-react` integration in a real React + TanStack Router + TanStack Query stack.

## Tech stack
- Vite 8 + React 19
- TanStack Router v1
- TanStack Query v5
- Tailwind CSS 4
- TypeScript 7

## Setup steps

### 1. Create app
```bash
mkdir apps/demo
cd apps/demo
pnpm create @tanstack/start@latest
```

Add dependencies:
```bash
pnpm add @bluevoid/dyn-icons @bluevoid/dyn-icons-react @bluevoid/dyn-icons-react-devtools
pnpm add @tanstack/react-query @tanstack/react-router @tanstack/react-query-devtools
pnpm add tailwindcss @tailwindcss/vite
```

### 2. Vite config
`vite.config.ts`
```ts
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwind from '@tailwindcss/vite'
import { tanstackStart } from '@tanstack/react-start/plugin/vite'

export default defineConfig({
  plugins: [
    react(),
    tailwind(),
    tanstackStart(),
  ],
  server: { port: 3000 }
})
```

### 3. Query client bootstrap
`src/integrations/queryClient.ts`
```ts
import { QueryClient } from '@tanstack/react-query'

export const queryClient = new QueryClient({
  defaultOptions: { queries: { staleTime: 1000 * 60 * 60 } }
})
```

Wrap app:
```tsx
<QueryClientProvider client={queryClient}>
  <RouterProvider router={router} />
</QueryClientProvider>
```

### 4. Dyn-icons config
`src/lib/dynIconsConfig.ts`
```ts
import { defineDynIconsConfig } from '@bluevoid/dyn-icons'

export const dynIconsConfig = defineDynIconsConfig({
  icons: {
    cacheClientPath: '/icons',
    providers: ['tabler']
  }
})
```

### 5. Prefetch on bootstrap
In `src/router.tsx`:
```ts
await queryClient.prefetchQuery({
  queryKey: ['dyn-icons', 'tabler', 'manifest'],
  queryFn: () => fetch(`/icons/tabler/pages/manifest.json`).then(r=>r.json())
})
```

### 6. Routes
Create routes under `src/routes/`:
- `/test-dyn-icon-cache` - uses `useDynIcon` prefetch
- `/test-dyn-icon-picker` - uses `useDynIconPage`
- `/test-dyn-icon` - renders `<DynIcon i="tabler:home" />`

### 7. Components
`src/components/DynIconExample.tsx` demonstrates:
- `useDynIcon` for paths
- `queryClient.getQueryData` for synchronous read after prefetch
- Fallback to `IconQuestionMark` while loading

### 8. Devtools
Add:
```tsx
import { DynIconsDevtools } from '@bluevoid/dyn-icons-react-devtools'
import { TanStackQueryDevtools } from '@tanstack/react-query-devtools'

<DynIconsDevtools />
<TanStackQueryDevtools />
```

### 9. Run
```bash
pnpm --filter demo dev
```

The demo requires a built icons cache under `public/icons/` generated by `dyn-icons` CLI.

All files needed to reproduce are in `apps/demo` - copy src structure, vite config, and dependencies listed above.
